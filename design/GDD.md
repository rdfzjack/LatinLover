## 0. 约定

- 来源标记：**[用]** 用户定；**[原]** 原版规则（美少女梦工厂 2；见 `original/SUMMARY.md`、`original/data/tables/`）；**[推]** 推定，理由见 `DESIGN_NOTES.md` 同编号条目（如 [推N3]）。

- 金钱单位是 1920 年代的美元，全部为整数 [用]。
- 数值用试算器（`sim/`）调过一轮，记录在 `design/BALANCE_LOG.md`。本文和 `data/new/*.json` 不一致时以 JSON 为准。

## 4. 月流程与结算顺序

每月按下面顺序执行 [原骨架][推N17]：

1. **月初**
   1. 扣生活费（5.7），可负债。
   2. 1、4、7、10 月：出选片板，可试镜（6、7）。
   3. 自由操作，不占日程：街道（5.8）、和 Sil 谈话（5.8）、物品和装备、投稿剧本（6.5）。
   4. 玩家排本月 3 旬的日程；被拍摄锁定的旬不能改。
2. **逐旬**（上、中、下）
   1. 旬初检查：临时换角、抢角（11.1）。
   2. 逐日执行日程；每天结算数值，然后过一天。
   3. 逛街的旬：在旬中触发该地点的一个事件（5.5.2）。
   4. 生日当天插入生日事件。
3. **月末事件**：按 11.2 表的顺序逐条判定，每月最多触发 2 个，其余顺延到下月再判 [推N17]。
4. **月结**
   1. 生活方式的体力效果。
   2. 上映结算（8）。
   3. 名气衰减（2.5）。
   4. 算生病指数、失控指数，更新状态（10）。
   5. 重病计数与倒下判定。
   6. 恋爱状态计时。
   7. 负债计数。
   8. 10 月：对手数值按表换到下一年 [原：10/31 对手成长]。
   9. 12 月：年度大事（12.1）。
   10. 时代事件（11.3）。
   11. 1929-12：进入结局判定（15）。

## 5. 日程

三类：练习（上课、看书）、打工、休息（含逛街）；拍摄由片约自动锁定。街道是不占日程的自由操作（5.8）。

### 5.1 每日成功判定

- 练习（上课和看书）[原]：`体力/2 + r0(体力/2) >= r0(疲劳)` 成功才有收益；不论成败疲劳 +1，上课另扣学费。
- 打工、拍摄 [原]：`属性 − r0(疲劳) >= 成功线`。
- 追加失败 [原]：恋爱状态中 20%；失控指数 10–29 时 40%，≥30 时 80%（当天偷懒，只对打工和拍摄）。
- 生病状态本身不改任何日程的成功率 [原 N18，核对过 `SUCCESS_CHK`]。成功判定里只有疲劳和体力；生病指数就是两者之差，所以病重时自然很难成功，不另加失败率。

### 5.2 课程等级 [原，门槛按总长度缩]

某门课上过的旬数 ≤3 为 1 级，≤6 为 2 级，≤9 为 3 级，之后 4 级 [推N1][推N59]。看书没有等级。

#### 5.3.2 看书 [用][推N53]

## 7. 试镜

结构 [用]；数字按节奏重推。

### 7.1 流程

1. 报名：名气 ≥ 门槛。
2. 双方各自秘密组 5 张牌。
3. 同时亮牌：双方看到对方 5 张牌的颜色和点数；同时揭晓场风（按角色的场风概率抽一色）。
4. 最多 5 轮，每轮双方同时出一张没出过的牌，比有效点数。
5. 先赢 3 轮的一方胜 [推N30]。
6. 大片连打 2 场，对手不同，第二场重新组牌、重新抽场风；两场都赢才算赢 [推N31]。

### 7.2 牌

- 四色 = 四条路，牌没有特殊效果 [用]。
- 玩家自己选 5 张的颜色 [用]。同色第 k 张（k 从 0 起）点数 = `max(0, 该路等级 − k)` [用]。

### 7.3 有效点数

```
v = 点数
if 牌色 == 场风: v *= 1.3            # [用：先 1.3，待测]
if 我克对方 且 对方牌色 != 场风: v *= 1.3，对方 v *= 0.8   # [用：可降，原 1.5/0.7；第 5 步降到 1.3/0.8，见 7.7]
```

- 克制环：硬汉克情人，情人克文化，文化克手腕，手腕克硬汉；相对的两色互不相干 [用]。
- 场风色不受克制（双方系数都不生效）[用]。
- 比较：大者胜该轮；相等则名气高者胜；仍相等对手胜 [推N32]。

### 7.4 结果 [推N33]

| 比分 | 结果 |
|---|---|
| 3:0 | 拿到角色；“被导演记住”：该角色的导演下一次出现时，玩家主色的场风概率 +10 个百分点（从最高的其他色里扣） |
| 3:1、3:2 | 拿到角色 |
| 2:3 | 惜败：可选同片配角（拍摄旬数 −1，最少 1；片酬 ×0.4；上映名气和声望修正 ×0.3；标签照记，不记“低成本制作”） |
| 1:3 | 落选 |
| 0:3 | 演砸：名气 −5%；20% 上报（曝光，名气再 −5%） |

大片第一场输按上表结算；第一场赢、第二场输一律按惜败。

### 7.5 对手的组牌 [推N34][用：副色防克制]

每个对手有主色张数 `k`（3、4 或 5）。主色 = `等级 × (1 + 0.3 × 该色场风概率)` 最大的颜色；其余 `5−k` 张取主色的“克星的克星”：克主色的那一色被谁克，就带谁。情人带手腕，硬汉带文化，文化带硬汉，手腕带情人。对手不傻，会防着被克的颜色抢角色。

### 7.6 对手的出牌习惯 [用][推N35]

每轮 80% 按习惯出，20% 在剩余牌里均匀随机。“大小”按对当前场风的有效点数（不计克制）排。

| 习惯 | 规则 |
|---|---|
| 抢先 | 从大到小出 |
| 压轴 | 从小到大出 |
| 开门红 | 第一轮出最大，之后从小到大 |
| 跟牌 | 第一轮出中间那张；之后出能赢过玩家上一轮那张牌的最小牌，没有就出最小 |
| 看比分 | 落后或平手时出最大，领先时出最小 |
| 随性 | 始终均匀随机 |

情报：
- 和某个对手交手满 2 次，或人脉 ≥60：组牌界面显示他的习惯和主色张数 `k`。
- 人脉 ≥80：组牌前排除场风概率最低的一色。
- Duv 的告密（6.5）：显示某个角色完整的场风概率。
- 餐厅侍者的里程碑（5.4）：每块板一个角色直接显示对手习惯。

### 7.7 试算结果（`python3 -m sim.audition`）

局面：一个情人角色，场风概率 硬/情/文/手 = 15/60/10/15；对手按 9.2 的无名规则组牌（情6 情5 情4 手4 手3），符合“对手贴合角色”；场风按角色概率抽；双方随机出牌；玩家取纯色或“主色 4/3 张 + 一种副色”里胜率最高的一副。克制 ×1.3/×0.8。

| 同路同级（情 6） | 24% | 32% / 12% | 62% |
| 同路低 1 级 | 2% | 3% / 0% | 12% |

### 8.1 时间

### 8.2 票房分

```
S = B × P × F × T
B: 小片 40 / 中片 100 / 大片 250
P: 拍摄表现（5.6）
F: 契合 = 0.6 + 0.4 × 平均( min(属性或技能/目标, 1.5) )，范围 0.6–1.2
T: 标签熟悉 = 1 + 0.03 × min(该角色各标签已有计数之和, 5)
```

结算：
- 名气 += `S × 0.3`（取整）。
- 分红 = `S × 2`。
- 该角色场风概率最高的那条路，声望修正 += 小片 2 / 中片 4 / 大片 8；`S ≥ 1.4 × B` 为大卖，翻倍。大卖要 P、F、T 三项都高（例如 P 1.2 × F 1.2 × T 1.0），试算里约一成的片。
- `S < 0.7 × B` 为扑街：不加修正，名气只加一半。
- 角色的每个标签计数 +1。
- 低成本计数：主演小片 +1，主演中片 −1，主演大片 −2，最低 0（8.4）。
- 以上各项 [推N36]。

### 8.3 有声片
