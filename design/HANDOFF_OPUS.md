## 第一件：正常片为什么一半不及格

第 5 轮量出来：自律打法后两年的主演片，28% 得分在 0.7–1.0，26% 在 0.7 以下。要知道是哪个数拖的。

用 `disciplined_*` 和 `bad_boy_*`，现在的数，各 100 局（种子 1–100）。局记录里每部上映片多存 P、F、T、是否戏路不合（×0.9）、是否口音（×0.6）、片子的路是不是主路。只看主演片，分前两年 / 后两年报：

1. 得分 X 的分位数（10 / 25 / 50 / 75 / 90），全部主演片一行，只算主路的片一行。
2. X < 0.7 的片和 0.7 ≤ X < 1.0 的片各一行：P、F、T 的平均；戏路不合占多少；口音占多少；拍摄旬里失败的天数占多少。
3. 这些低分片里，去掉口音就能到 1.0 以上的占多少；去掉戏路不合的占多少；把 P 换成 1.0 的占多少；把 F 换成 1.0 的占多少。
4. 按路分开（硬汉 / 情人 / 文化 / 手腕）报第 2 条里的口音占比和 F 平均。
5. 大片：每局试镜大片几次、赢几次；没去试的月份是卡在名气门槛、道德条款还是别的；机器人看到大片时是不是优先试它。
