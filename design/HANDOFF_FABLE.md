## 游戏现在是什么样（够你讨论用）

- 1920 年代好莱坞，培养男演员小咪，1926-01 到 1929-12，48 个月。每月排三旬日程：上课、看书、打工、休息（在家 Sil 陪着／外出选去处）、拍戏占旬。每季度一块选片板（16 块），用卡牌试镜抢角色；最后按四条路（硬汉、情人、文化、手腕）的声望、名气和品性进结局。
- 四条路各 3 个技能，声望 = 技能 + 装备加成 + 上映、年度大事、机遇给的修正。等级随声望自动变（用户定的，不做手动升级）。
- 试镜：5 张牌，颜色 = 四条路，点数 = 本路等级递减；5 轮里先赢 3 轮的拿到角色；有场风、克制环、对手出牌习惯。对手分有名（逐年等级表）和无名（按时间涨级）。
- 拍片：小 / 中 / 大片占 1 / 2 / 3 旬，按体力、疲劳判定每天成败；上映看表现、贴合、标签熟悉度，出大卖 / 扑街，给名气、分红、声望修正和标签计数（定型）。有声片从 1927-10 开始，看谈吐。
- 事件：月末事件（失踪、逮捕、丑闻、债主、毒品、长约……）、机遇、逛街和 NPC 日程、打工接口事件、7 个时代节点、12 月年度大事、四条感情线、物品和装备。
- 结局：特殊结局 → 大类 → 档次（S 451 / A 381 / B 311 / C 211）→ 结局表；另有品性档、归宿和总分。
- 两套实现：Python 试算器（`sim/`，一条命令跑几百局出报告）和 Godot（`game/`，已移植全部逻辑，和 Python 逐字节对账）。界面还没做，用户还不能自己玩（第 13、14 步做界面）。

和用户谈定以后，写一份 `design/PROPOSAL_<主题>.md`（中文），内容：

1. **问题**：一两句话，用户原话的意思加你的理解。

5. **实施任务**：拆成 PLAN 那样的步骤，每步写 做什么 / 改哪些文件 / 完成标准 / 难度 / 模型（逻辑难的给 Opus，填表、移植、文档给 Sonnet）。注意：

   - 如果要插在第 13 步（界面）之前做，写明理由；不急的可以排到第 13–15 步之后。
6. **要用户拍板的**：只列真正需要用户决定的设计取舍，能自己判断的不要问。
