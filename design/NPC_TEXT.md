# 文案粗稿 · 可攻略角色

本页是十位可攻略角色的全部文案粗稿（Sil、Duv 由策划自写）。括号里是好感、人样和标记变化；“人样−”在游戏里只显示提示，不显示数值。结算五档为：红了、糊了、进去了、回码头、犯罪皇帝。

## 诺瓦

**好感逻辑**：偷偷喜欢坏男人，但必须让他觉得自己有罪。修罗场类型：accept。

### 戏中寒暄

**对手戏（他赢）**：“对不起……这个角色本来该是你的。”

- A「那你让给我」：他真去找导演说要让，导演没同意，他回来又道歉了一次。（+5）
- B「没事」（+0）
- C「那你请我吃饭」：他带你去了教堂隔壁的素菜馆。（+3）

**对手戏（你赢）**：“恭喜……我是真心的。我待会儿要去告解一下，刚才我嫉妒了。”

- A「你嫉妒我什么？」：他脸红了，“……颛骨。”（+3）
- B「我陪你去」（+4）
- C「告解的时候提我名字」（+5，人样−）

**搭档戏**：吻戏开拍前，他小声问：“我们可以借位吗？”

- A 借位（+2）
- B 不借：拍完他直接去告解了。（+5，人样−）
- C「你先去问问神父」：他真去问了。（+3）

### 偶遇（教堂）

**前期**：小咪抱着捐款箱从侧门出来，迎面撞上来告解的诺瓦。“你……也是来捐款的？”

- A「我在帮忙搬」：他帮你一起搬，搬到你家门口才觉得哪里不对。（+0）
- B「我在偷」：他沉默很久，“我替你去告解。”（+8，人样−）
- C 把箱子塞给他就跑：他被神父当成了小偷。（−3，标记“替你背过锅”）

**中期**：你躲进告解室，他在隔壁格子以为你是神父，开始告解，内容全是你。

- A 继续装神父，判他“今晚来我家赎罪”（+6，人样−）
- B 咳嗽一声，暴露自己（+1）
- C 全记下来，第二天找他要封口费：他付了，还向你道歉。（+4，标记 nova.heldConfession）

**后期**：他在点蜡烛，求事业别被新人压下去。

- A 吹灭他的蜡烛，换上你自己的愿望（+3）
- B 把蜡烛偷去卖（+4）
- C 跪在他旁边大声替他祈祷：“让诺瓦再犯一次错。”（+5）

### 派对

他是全场唯一拿着水的人。“听说瓦伦又和蛇蝎吵起来了，摔了一整套茶具……啊，我不该在背后说别人。对不起。”

- A「接着说」：他讲完，脸色发白，说待会儿要去告解。（+2）
- B「我知道得更多」，然后现编一段：他一边听一边画十字。（+2，人样−）
- C「你今天告解几次了？」：“……三次。”（+1）

### 年度聚会

他一个人站在角落喝水。“新年愿望……我想少犯一点罪。你呢？”

- A「我想多犯一点」（+6）
- B「跟你一样」：他不信。（+2）
- C「我帮你犯」：他一口水呛住了。（+4，人样−）

### 越线（第 1 拍）

《宾虚》杀青派对，他第一次喝酒，喝醉了，把这辈子的歉都向你道了一遍。

- A 带他回家：第二天他去告解，神父问得比小报还细。（越线）
- B 送他去教堂（停在同事）
- C 把他留在派对上，让女王接走（搞砸，−15）

### 线内拍

**第 2 拍 · 腰布**：你偷了他《宾虚》里那块腰布。

- A 拿去卖：买家排到了门外。（+2，人样−）
- B 还给他（+1）
- C 穿着它去见他：他羞到当场跪下忏悔。（+5）

**第 3 拍 · 新拉丁情人**：瓦伦死后，片厂把他捧成新的拉丁情人，压过了你。他每赢你一次，就在床上道歉一次。

- A 故意让他赢（标记 nova.guiltMax）
- B 把角色抢回来：他松了一口气。（+3）
- C 把他的道歉偷偷录下来（标记 nova.heldConfession）

**第 4 拍 · 三个修女姐姐**：他三个当修女的姐姐来探亲。你躲进告解室，被她们当成神父，听了一下午告解，知道了诺瓦小时候所有的糗事。

- A 赦免她们（标记 nova.familyApproved）
- B 按次收费（人样−）
- C 告诉她们你是诺瓦的人：三个人一起晕倒了。（+3）

**第 5 拍 · 修道院**：他宣布要去修道院。

- A 跟他一起去（标记 nova.monastery）
- B 把他的告解内容卖给小报（标记 nova.soldConfession）
- C 你自己去告解，神父听到一半辞职了（标记 nova.priestQuit）

### 结算

**标记覆盖**（优先）

- nova.monastery 且 nova.familyApproved：你们俩在修道院当了修士，你负责酿酒，酒窖年年亏空。院长每周要听你们两个人告解，第三年申请调走了。
- nova.soldConfession：小报连载《禁欲美男忏悔录》。他读完来找你，说“写得比我说的好”，从此每周给你送新素材。
- nova.priestQuit：全城的神父都拒绝再听他告解，他只能向你告解。你成了他唯一的神父，按次收费。

**按状态**

- 红了：你压过了他，他终于不用再道歉，改成要你向他道歉，你按次收费。
- 糊了：他一直说要救你，救了三年，只救出来一本告解记录。
- 进去了：他每周来监狱听你告解，狱警以为他是神父，他也没否认。
- 回码头：三个修女姐姐收留了你，你在修道院厨房打工，诺瓦每周都来“探望姐姐”。
- 犯罪皇帝：帮派每次干完活都派他去告解，他替整个帮派道歉。神父手里的情报比警察还全。

### 修罗场

- 现任反应：向新人鸞躬，“对不起，是我来晚了。”然后去告解。
- 你还回来干嘛：“……你不在的这一年，我替你告解了五十二次。”

## 库普

**好感逻辑**：忠犬型，要你认真对他。跟他正面较量、打赢他，好感最高；撒娇让他放水会扣分。修罗场类型：accept。

### 戏中寒暄

**对手戏（他输了）**：沉默半天，“……你很厉害。”

- A「你也不错」（+3）
- B「那当然」：他点点头，“嗯，那当然。”（+5）
- C「你是不是故意让我？」：他慌了，解释了很久，是他这辈子说过最长的一段话。（+0）

**对手戏（你输了）**：“……对不起。”

- A「那你请我吃饭」：他请了，自己一口没吃，看着你吃完。（+3）
- B「下次我打赢你」：“好，我等你。”（+6）
- C 撒娇要他下次让你：他很认真地说：“不行。”（−3）

**搭档戏**：一场打斗戏，他要假装打你，开拍前说：“……我不敢打你的脸。”

- A「打身上」（+2）
- B「真打」：他不肯，导演喊卡后他一直跟你道歉。（+3）
- C「打脸要加钱」：他自己掏钱给了你。（+4）

### 偶遇（片场）

**前期（他还是替身）**：他刚替主角从二楼摔下来，躺在垫子上。小咪在旁边搬道具。

- A 扶他起来（+2）
- B 趁他躺着，把他的盒饭吃了：他看着你吃完，问：“……好吃吗？”（+4）
- C 跟副导演说你也能摔，把他下一条的替身钱抢过来：你摔了，他在下面接住了你，钱归你。（+5）

**中期（他刚有了自己的化妆间）**：你来送道具，看见桌上有吃的，就吃了起来。他进门撞见。

- A 道歉（+1）
- B「你的化妆间比我住的地方还大」：他给了你一把钥匙。（+5）
- C 叫他出去，说你还在用：他真出去了，在门口站了一个小时。（+3）

**后期（片场里的首映礼后台）**：他被记者围住，看见你挤了过来。

- A 冒充他的经纪人收采访费：他点头配合。（+4）
- B 当着记者的面说他欠你钱：他当场掏了钱。（+3）
- C 把他推给记者，自己去吃自助餐（−1）

### 派对

他不会讲八卦，憋了半天，只说了一句：“……舞池女王在找你。”

- A「你吃醋？」：“……没有。”他把手里的酒一口喝完了。（+3）
- B「她大概是找我借钱」：他马上说：“我可以借你。”（+1）
- C「那我去找她」：他没说话，站在原地把一整瓶喝完了。（−2）

### 年度聚会

他在你旁边站了一整晚，一句话没说。零点时他开口：“……新年快乐。”

- A「新年快乐」（+3）

- C 亲他一下（好感 45 以上才出现）：他站着一动不动，一直站到天亮。（+8）

### 越线（第 1 拍）

补拍到半夜，一场爆破戏他替你当了替身，被炸得满脸黑。你把他拖回化妆间，顺手摸走了他的钱包。他看见了，只说：“……拿吧。”

- A 那晚没走（越线）
- B 把钱包还给他，回家（停在同事）
- C 拿着钱包去叫舞池女王来照顾他（搞砸，−15）

### 线内拍

**第 2 拍 · 金表**：他拿第一笔像样的片酬买了一块金表送你，你第二天就当了。他在当铺橱窗里看见，又买回来，再送你一次。

- A 再当一次：他第三次买了回来。（+2，人样−）
- B 戴着（+4）
- C 把当票塞给他：“你自己留着吧。”（+3）

**第 3 拍 · 《翼》（1927）**：舞池女王也在组里，他同时在跟她来往。三个人在同一辆拖车里撞上了，记者蹲在外面数进进出出了几次。

- A 拉他俩一起出去面对记者（+3）
- B 从拖车窗户翻出去跑了（+0）
- C 把三人同框的照片卖给记者（+2，人样−）

**第 4 拍 · 顶罪**：你的货被警察查出来，他冲上去说：“是我的，我自己吸的。”警察看他一脸健康，不信。他当场学你犯瘾时浑身发抖的样子，学得一模一样，因为他天天看着你。

- A 让他被带走（标记 cooper.tookBlame）
- B 自己认了：他在警局门口等了你一夜。（+5）
- C 趁乱把剩下的货也塞进他口袋（+1，人样−，标记 cooper.tookBlame）

**第 5 拍 · 《弗吉尼亚人》（1929）**：他那句名台词是“叫我那个的时候，笑一笑”。

- A 当众叫他外号：他真的笑了。（+3）
- B 叫他“欠债的”：他也笑了。（+2）
- C 什么都不叫：他慌了，追着问你他是不是哪里做错了。（+4）

### 结算

- 红了：两个人抢同一个主角，导演让你们比试定输赢。他故意输了，输完还笑了。
- 糊了：他每部片都要求把你写进片尾字幕，职务那一栏写的是“库普的”。
- 进去了：他替你顶罪没顶成，两个人一起进去了。他把牢房收拾得跟化妆间一样，门上写着你们俩的名字。
- 回码头：他把你搬货的那个码头买了下来，你照样在那儿搬货，老板天天跑来帮你扛。
- 犯罪皇帝：他每次都替你顶罪。警局门口有一条长椅是他捐的，上面刻着“顶罪专用”。

### 修罗场

- 现任反应：“……我在门口等。”他真去门口站着了。
- 特殊配对（与舞池女王）：三个人在同一辆拖车门口撞上，库普先让开了路：“……你们先。”
- 你还回来干嘛：“……门口那个位子，我一直留着。”

## 甜心

**好感逻辑**：势利，外甜内狠，喜欢偷情。有钱、敢当着她丈夫的面乱来，好感加；说她像小女孩，好感大减。口癖：“我的形象不是这样的。”修罗场类型：accept。

### 戏中寒暄（只有合作对手戏）

**合作 1**：拍爱情戏，靠近时她压低声音：“别贴这么近，你身上一股码头味。”

- A 退后一点（+0）
- B 再贴近一点：她没再开口，导演喊卡她才把你推开。（+4）
- C「你闻得出来？你去过码头？」：她顿了一下，“……小时候去过。”（+3）

**合作 2**：收工后她补着妆问你：“刚才那条我演得怎么样？”

- A「像个小女孩」：“我的形象不是这样的。”（−8）
- B「比我演得好」（+2）
- C「比你丈夫演得好」：她笑了，没反驳。（+4）

### 偶遇（拳馆，她来接范班克）

**前期**：你在拳馆躲债，范班克以为你来练拳，拉着你对打了一上午。甜心在门口的车里等他，问：“道格拉斯，这是谁？”

- A「我是您丈夫的新陪练」（+2）
- B「我是来躲债的」：她压低声音问你欠了多少。（+5）
- C 跟着上车回他们家吃早饭：范班克夸你胃口好，甜心看着你把她那份也吃了。（+3，标记“去过皮克费尔”）

**中期**：她的车停在拳馆门口，范班克还在里面打沙袋。她摇下车窗：“上车。”

- A 上车：范班克出来没看见车，自己跑回了家。（+5）
- B 继续进去给范班克当陪练（+1）
- C 上车前先进去找范班克借车费：他借了。（+4）

**后期（她刚剪了短发）**：她戴着帽子来接人，遮着新发型。

- A 掀她的帽子（−3）
- B「短发显老」（−5）
- C「短发好，晚上偷偷出门不容易被认出来」：她笑了，“你懂。”（+4）

### 派对

**第 2 拍 · 住家陪练**：范班克嫌你来回跑太浪费时间，让你直接住进客房。陪练费从甜心的账上走。

- A 跑完全程：你吐在了他们家的喷泉里。（+2）

**第 4 拍 · 剪发（锚点 1928-07）**：她剪掉了出名的长卷发，全国哗然。剪下来的卷发放在妆台上。

- A 偷去卖给假发商：门口排了一条街。（+2，人样−）
- B 留一缕放在自己口袋里（+4）
- C 按市价卖回给她：她付了，还讨了价。（+5）

**第 5 拍 · 记者堵门**：记者堵在皮克费尔门口问：“您丈夫知道吗？”

- A 让范班克自己回答：“当然，他是我们家的运动员。”（+3）
- B 当场勒索甜心（+2，人样−）
- C 勒索范班克：他以为是要赞助，开了支票。（+1，标记 sweetheart.blackmailedDoug）

- 进去了：范班克亲自出庭给你当品德证人，说你“每天晨跑”。甜心戴着墨镜坐在旁听席最后一排。
- 回码头：联艺的豪车每周三停在码头，没人知道车上运的是什么。
- 犯罪皇帝：范班克以为你开的是健身连锁，入了股。甜心帮你管账，比你还狠，抽三成。
- 变体（sweetheart.blackmailedDoug）：追加一句“范班克到现在还以为那是赞助。”

- 你还回来干嘛：“道格拉斯还以为你去参加集训了。”

**第 4 拍 · 片场（1928）**：她拿到了电影合同，片场里停着一架能飞的真飞机当道具。你在片场开盘，赌她今天会不会把它开走。

- A 押会：她真开走了，你赢了。（+3）
- B 押不会，偷偷拔了油管（+1，人样−）
- C 坐上去跟她一起开走（+5）

**第 5 拍 · 保险公司**：保险公司来查，怀疑有人押了自己的坠机。

- A 让她顶罪（+0）
- B 你自己顶罪（+5）
- C 两个人一起把调查员灌醉：他最后也下了一注。（+4）

### 结算

- 红了：她押你会红，赢了一大笔，买了一架飞机，你们俩开着它去逃税。
- 糊了：她押你红不起来，赢了，拿这笔钱把你包了下来。
- 进去了：她开盘赌你几年能出来，全城都下了注，你在牢里也下了一注。
- 回码头：她第五次结婚，请你当伴郎，婚礼上你当场开出赔率。
- 犯罪皇帝：她开飞机给你运私酒，每一趟都先押自己会不会掉海。掉了三次，货一箱没少。
- 变体（elder.partner）：追加一句“你们的盘口至今还开着。”

### 修罗场

- 现任反应：当场开盘，赌你最后会选谁。
- 你还回来干嘛：“我押你会回来。赢了。”
