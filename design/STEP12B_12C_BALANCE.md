# 第 12b、12c 步：把试算搬进 Godot，然后做第二轮平衡

第 13 步（界面）之前做。12b 是机械移植（Sonnet），12c 是规则和数值（Opus 写规则，Fable 只看报告定数）。一步一个对话。

## 为什么有这两步

- 现在规则有两份：`sim/`（Python）和 `game/silentstar/core/`（Godot）。能批量试算的机器人只在 Python 里。
- 第二轮平衡要改规则（疲劳、毒品、被捕、疗养院），不只是改表。规则每改一次都要两边各写一遍再对账。
- 所以先把机器人和报告搬到 Godot（12b），之后规则只在 Godot 改一处（12c 起），`sim/` 冻结不再维护。

## 12b：机器人和报告搬到 Godot（Sonnet，中）

**只做移植，不改任何规则和数值。** 发现 Python 有 bug 也不要修，记在交付说明里。

### 读

`sim/bots.py`、`sim/report.py`、`sim/story.py`、`game/silentstar/core/story.gd`、`design/IMPL_NOTES.md` 的 Godot 一节。别的文件用到再查，不要通读 GDD。

### 做（按顺序）

1. **先换机器人的随机数（Python 侧）。** `Bot.__init__` 用的是 `random.Random`，Godot 复现不了。把它换成 `sim/rng.py` 里的 PCG32（单独一个实例，种子还是 `seed * 1000003 + 17`，不要和游戏的两条随机流共用）。`bots.py` 里所有 `self.rnd.xxx` 调用改成这个实例上等价的整数取法；`shuffle`、`choice`、`random()` 之类各自写成用整数随机数实现的小函数，写法要能在 GDScript 里逐行照抄。改完跑 `python3 -m unittest discover -s tests/new -t .` 和 `python3 tools/check.py`。
2. 重跑 `python3 -m sim.report`，把 `design/BALANCE_LOG.md`“现在的报告”整段换成新输出，在“改动记录”加一句“机器人随机数换成 PCG32，数字有小幅变动，规则没变”。**这份输出就是 12b 的基准。**
3. 移植 `sim/bots.py` → `game/silentstar/tools/bots.gd`：`Est`、辅助函数、`Bot` 和 8 个子类、`play`、`summarize`。类名、方法名、字段名和 Python 一样。遍历字典的地方按 Python 的插入顺序（Godot 的 Dictionary 也保序，但要确认来源顺序相同）；排序遇到相等时的先后要和 Python 一致（Python 的 sort 稳定，GDScript 的 `sort_custom` 不稳定，需要时加下标做第二关键字）；浮点运算保持同样的运算顺序。
4. 对账：在 `tools/trace_cases.json` 加一段 `bots`，每种机器人 5 个种子（1–5）。`tools/trace.py` 和 `game/silentstar/tools/trace.gd` 各加一段输出：每局每月一行（月份、存档 md5），最后一行 `summarize` 的 JSON。按 IMPL_NOTES 的三条对账命令跑，`compare_trace.py` 必须无差异。
5. 移植 `sim/report.py` → `game/silentstar/tools/report.gd`。命令：
   ```
   godot --headless --path game/silentstar --script res://tools/report.gd -- --n=200 --bots=all
   ```
   参数和 Python 的一致（`--n` `--bots` `--no-buy`），另加 `--seeds=a-b`（方便开几个进程分段跑）。输出格式逐字符照 Python 的。
6. 用 `--n=200` 跑一遍，和第 2 步的基准 `diff`，必须完全一样。
7. 文档：`README.md`“常用命令”和“现在做到哪”、`PLAN.md` 进度、`design/IMPL_NOTES.md` 的 Godot 一节加上新命令；写明“`sim/` 从 12b 起冻结：不再改规则，只留作历史参考；规则只改 `core/`”。

### 不许做

- 不改 `data/new/` 任何表，不改 `core/` 的规则逻辑（为了能调用而加的只读接口可以，加了要在 IMPL_NOTES 写一行）。
- 不“优化”机器人的策略，不合并、不重命名、不删机器人。
- 不删 `sim/`、`tests/new/`、对账工具。
- 对不上账时不许改基准或放宽比较来过关。找到第一处差异，修 Godot 侧。同一处差异试了三种修法还对不上，就停下，把差异行和试过的修法写进交付说明。

### 完成标准

第 4 步对账无差异；第 6 步 `diff` 为空；Godot 跑 200 局 × 8 种机器人的耗时写进 IMPL_NOTES（超过 10 分钟就在交付说明里报出来，不要自己去改算法）。

## 12c：第二轮平衡（Opus 写规则；Fable 看报告定数）

### 现在为什么“太顺”（已核对 GDD 和报告）

| 现象 | 原因 |
|---|---|
| 疲劳不是约束 | 上课、看书每天只 +1（一旬约 +10），在家一旬 −50，城里外出 −100，度假村 −300。上五旬课歇一旬就清零。所有专练机器人“倒下”0%、负债 0 |
| 自律没有用 | 自律只进失控指数（疲劳 − 自律）。疲劳上不去，自律多少都一样 |
| 毒品不是玩法 | 药瘾阶段只由月末事件 1/4 概率推进，玩家不能主动用，也不进任何公式 |
| 犯罪线不富也不险 | 犯罪线机器人期末现金 3.4k，比专练的还少；被捕只在看场子 1/30、运私酒 1/20 时判定，罚款最多 500 |
| 坏孩子当不了明星 | 犯罪 ≥300 永久不能报大片；犯罪线 96% 是 C 档 |

### 设计：两种对付疲劳的办法

疲劳成为所有路线的短板。对付它有两条路，代价不同：

- **自律线：扛着。** 自律高，失控指数就低，能带着疲劳干活。代价是时间和钱：攒自律要去教堂（日薪 1），而且休息得多。
- **坏孩子线：抹掉。** 用毒品把疲劳直接清掉，不花日程。代价是药瘾、被捕、戒断占掉整月，起落大。

两条路都能不偷懒地排满日程，区别在付的是什么。

### 规则改动（c1，Opus，只改 Godot）

数字都是起点，c3 再调。每条都要写进 GDD 对应小节，并在 `data/USER_GUIDE.md` 补新字段。

1. **疲劳来源（5.1、5.3）**：上课、看书每天疲劳 +1 → 课程表每门课加字段 `fatigue_per_day`，起点 3；看书 2。年度大事每次疲劳 +15（`annual.json` 加效果）。
2. **恢复手段（5.5）**：在家 −5/天不变。片厂区、市中心、海滨大道、码头从 −10 改成 −3（它们是去见人的，不是去歇的）。度假村 −30 → −20，度假村随机表加一类“玩过头”事件（权重约 1/4，疲劳 +15）。餐厅（5.8）每旬只生效一次。
3. **毒品变成玩家动作（2.6、5.8、11.2）**：
   - “递药”事件接受后，街道多一个动作“提神”：花钱（起点 20），疲劳 −40，不占日程，每旬最多一次。
   - 新隐藏值“药瘾点数”，每用一次 +1，自律 −5。阶段由点数决定：≥1 为 1，≥5 为 2，≥10 为 3。原来的“加深”事件删除。
   - 阶段 2：某月一次没用，月末疲劳 +20（戒断反应）。阶段 3：每月体力 −5、相貌 −3，Sil 或 Duv 触发“戒断”（照旧占掉下月，体力 −20，疲劳清零，点数归 0）。
   - 自律 ≥150 时“提神”不可选（他不碰）。
4. **被捕（11.2）**：罚款 `min(金钱, 500)` → `max(200, 金钱×30%)`，钱不够扣到 0；下一旬日程作废（拘留）。看场子、运私酒的搜查概率改成随犯罪值升高：`基础概率 ×(1 + 犯罪/100)`。
5. **道德条款（10）**：“犯罪 ≥300 永久不能报大片”改成“被捕或丑闻曝光后 3 个月内不能报大片”。长约解约照旧。
6. **犯罪工的收益（5.4）**：看场子、运私酒每天体力 +1；运私酒日薪 30 → 40。
7. **疗养院副作用（5.5、10）**：出院时相貌 −10、体态 −10；1/3 概率触发事件“疗养院里的人”（占位：Sil、Duv 好感各 −10，记一个旗标给后面的剧情用）。

### 新机器人（c2，Opus）

在 `tools/bots.gd` 加三个，原有 8 个不动：

| 名字 | 玩法 |
|---|---|
| 自律 | 专练一路；失控指数 ≥10 就去教堂或在家休息；从不“提神”，从不做犯罪工 |
| 坏孩子 | 专练一路；打工只挑看场子、运私酒；疲劳 ≥40 就“提神”；被送去戒就去 |
| 嗑药冲 S | 专练一路；不做犯罪工；疲劳 ≥40 就“提神”；阶段到 3 前一个月主动“送去戒” |

每个都按四路各跑一遍。报告加一段：休息旬占比、被捕次数、戒断次数、疗养院次数、作废的旬数、“提神”次数、现金 p10。

### 目标（c3，Fable 看报告，Opus 改表）

200 局中位数，四路平均。达不到就调上面各条的数字，每次只动一两个数，改完记进 `BALANCE_LOG.md`。

| 指标 | 自律 | 坏孩子 | 嗑药冲 S |
|---|---|---|---|
| 休息旬占比（在家+外出+教堂） | 30–35% | 15–20% | 10–15% |
| 作废的旬（拘留、戒断、疗养院、失踪） | ≤3 | 6–12 | 6–10 |
| 被捕次数 | 0 | 2–4 | 0–1 |
| 戒断次数 | 0 | 1–2 | 2–3 |
| 练满月 | 21–26 | 18–24 | 16–21 |
| 第 2 年末现金 | <1,000 | 2,000–4,000 | <1,500 |
| 期末现金 中位 / p10 | 2k–4k / >0 | 6k–10k / <1k | 3k–5k / >0 |
| S 档 | 5–15% | 15–25% | 30–40% |
| A 档以上 | ≥80% | 55–70% | ≥75% |
| C 档以下 | <2% | ≥15% | <10% |
| “倒下”结局 | <1% | 3–8% | 5–10% |

读法：自律线稳但穷、慢、难到 S；坏孩子有钱但两头分化；S 主要靠会用药的人拿。

`BALANCE_LOG.md`“下一轮要修的”三条（情人 S 档偏高、只读书文化钱多、手腕第 2 年钱多）并进 c3，等基线变了以后再看还在不在。
