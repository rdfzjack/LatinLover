# 小咪养成计划：交接说明

一个 1920 年代好莱坞题材的养成游戏的设计。玩家培养男演员“小咪”，从 1926-01 到 1929-12，每月排三旬日程（上课、看书、打工、休息、拍戏），每季度在选片板上用卡牌试镜抢角色，最后按四条路的声望、名气和品性进结局。规则骨架借自《美少女梦工厂 2》，题材、数值和试镜是新做的。

## 文件

| 文件 | 内容 |
|---|---|
| `GDD.md` | 现行的全部规则和数值。以它为准 |
| `DESIGN_NOTES.md` | GDD 里每个 [推N…] 为什么这样定；N60 是粗算结果；末尾是还要用户给的东西 |
| `PLAN.md` | 从 GDD 到 Godot 的 19 步实施计划，一步一个对话 |
| `tools/pacing_trial.py` | 节奏粗算脚本（见下） |

这个分支只放新游戏的设计，和别的分支没有共同历史。原版游戏的逆向资料（规则摘要、脚本索引、数据表、原版模拟器）在同一个仓库的 `main` 分支，只有 PLAN 第 1 步要用。设计文档的旧稿和修改过程在 `claude/brave-pasteur-qqq8q1` 分支，不需要看。

## 现在做到哪

- 设计文档完成，用户看过并确认了结构。内容（角色、事件、NPC、文本）大多还是占位。
- 数值只过了一轮粗算，四条路的节奏对上了用户的目标，钱有一处没对上（见下）。
- 新游戏的代码一行没写。`PLAN.md` 的 19 步都还没开始，下一步是第 1 步。

## 用户定过的事（不要改）

- GDD 里标 [用] 的全部。
- 一局 1926-01 至 1929-12，每月 3 旬，逐日结算。
- 节奏目标：专练一路在第 16–21 个月练满；前两年钱紧；期末现金不过万；练满加普通上映能过 311；大卖不能是常态。
- 大事件按故事节奏排，不必符合史实。瓦伦去世在 1927-08 已确认。
- 金钱是当年的美元，不出现小数。
- 名字都是占位，用普通词；人物细节等用户给，不要自己编。

## 没定的事

- **手腕路的钱。** 它没有学费，粗算里比别的路有钱得多（不买车时期末约 13,200）。用户倾向给它加开支，也接受它有钱，要等试玩后再定。现在没有动。见 DESIGN_NOTES N63。
- 会出声的短片、学院成立、试音三个时代节点是模型加的，用户没有逐个看过。
- 大片通过率偏高、硬汉路声望多 30 点等，列在 GDD 第 17 节。
- 内容类的待办在 DESIGN_NOTES 末尾。

## 复现粗算

```bash
python3 tools/pacing_trial.py
```

```bash
python3 tools/pacing_trial.py --buy
```

```bash
python3 tools/pacing_trial.py --buy --contract
```

只用标准库，一次约 10 秒。种子固定，三条命令的输出应该和 DESIGN_NOTES N60 的表逐字对上。

**脚本做什么。** 四种机器人各跑 400 局，每局专练一条路：钱够就练主路（留出下月生活费），不够就打工，疲劳到线就去逛街，自律低于 35 去教堂义工，主路练满后练第二条路。`--buy` 让机器人有余钱时买本路装备，`--contract` 让它在条件够时签长约。

**算了的。** 真实日历逐日结算；练习、打工、拍摄的成功判定；失控状态的偷懒；课程等级、加薪、全勤；看书；名气档和生活费；名气衰减；选片板和试镜（按 GDD 7.2–7.5 算有效点数，玩家在“主色 k 张加一种副色”里挑期望胜率最高的一副，出牌随机配对）；大片两场；惜败拿配角；拍摄、片酬、上映、声望修正、有声片惩罚；年度大事排名。

**没算的。** 事件链、感情线、工作线里程碑、前辈认可、机遇、生病和医院、讲究档生活、股票和股灾、对手的出牌习惯。逛街粗略算成每旬花 20、一半的旬给一项技能 +2。角色是随机生成的（主色 55%，其余各 15%；契合按是否对路抽一个区间），不读角色表。

**数值在哪。** 脚本开头的 `CFG`、`NAMED`、`BASE_AT`、`BASE_SK`、`ORIGIN`、`ITEMS` 是从 GDD 手抄的，每项旁边注了 GDD 的小节号。改 GDD 的数值要在这里同步改，再重跑。

**怎么读输出。** 每条路两行。第一行按表头依次是：练满月份（中位/10%/90%，999 是没练满）和练满率；声望过 150、210 的月份；第二条路练满的月份；每年末现金中位数；平均负债月数；期末现金中位数和 90% 分位；“练满＋上映修正”的中位数和过 311 的比例；再加年度大事后的中位数；主演的小/中/大片部数、试镜胜率、大片两场通过率；期末名气；期末谈吐；吃口音惩罚的片数；各类日程占的旬数。第二行是诊断：三项技能各自练满的月份、大卖率、各年末名气、练满那个月的现金、期末体力和自律、装备花费。

这个脚本只是在正式试算器（PLAN 第 4–7 步的 `sim/`）写出来之前用的。`sim/` 的报告出来后先和 N60 对一次，差得多的地方要查清是哪边的问题。
