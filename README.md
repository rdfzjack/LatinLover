# 小咪养成计划

一个 1920 年代好莱坞题材的养成游戏。玩家培养男演员“小咪”，从 1924-01 到 1929-12，每旬在地图上选一项日程（上课、打工、休息、拍戏），在固定的选片板上用卡牌试镜抢角色，最后按四条路的声望、名气和品性进结局。规则骨架借自《美少女梦工厂 2》，题材、数值和试镜是新做的。

现在做到哪、下一步、没解决的事：见 `PLAN.md` 的“进度”。

## 文档各管什么

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `CLAUDE.md` | 每个会话的规矩、目标分布、现在的判断 | 自动读到 |
| `README.md` | 文件地图、用户定过的事 | 每次开工 |
| `PLAN.md` | 进度（唯一的交接）、下一步、没解决的事 | 每次开工 |
| `design/GDD.md` | 现在的全部规则和数值 | 只读这次涉及的小节 |
| `design/TODO_RULES.md` | 还没做的新规则，做完一条删一条；和 GDD 冲突时以它为准 | 开工时看 PLAN 指到的那一节 |
| `design/ORIGINAL_MAP.md` | 原版的数和对应关系（属性对应、四路 pattern、原版工资档、年度比赛） | 做原版对应表时 |
| `design/DESIGN_NOTES.md` | GDD 里每个 [推N…] 的理由 | 想改某条规则前 |
| `design/BALANCE_WORKFLOW.md` | 改哪里、加内容／加系统／调平衡各怎么做、事件预算、护栏 | 改规则或调数值前 |
| `design/BALANCE_LOG.md` | 历次数值调整和报告 | 调数值前 |
| `design/CHANGE.md` | 用户早期的修改意见 | 查旧意见时 |
| `design/IMPL_NOTES.md` | 代码结构、接口、GDD 没写到的实现细节、对账命令 | 改代码时 |
| `design/GLOSSARY.md` | 中文名 → 英文 id（由 `tools/i18n_map.json` 生成） | 找 id 时 |
| `data/new/README.md` | JSON 表的条件、效果语法 | 改表时 |
| `data/USER_GUIDE.md` | 给用户的改表指南 | 改了表的写法时同步更新 |

`data/new/*.json` 是数值的真源；GDD 和它不一致时以 JSON 为准，并改 GDD。

## 常用命令

```bash
python3 tools/check.py
```

```bash
godot --headless --path game/silentstar --script res://tools/report.gd -- --n=200 --bots=all
```

报告参数：`--n` 局数，`--bots` 选机器人，`--no-buy` 不买装备，`--coverage` 事件覆盖，`--guard=design/targets.json` 护栏，`--seeds=a-b` 分段跑再 `--merge`。细节在 `design/IMPL_NOTES.md` 的 Godot 一节。

## 用户定过的事（不要改）

GDD 里标 [用] 的规则都是用户定的。下面是方向性的决定，按主题归纳。

**节奏和操作**
- 一局六年（1924-01 至 1929-12），每月 3 旬，一旬一旬在地图上点，逐日结算。
- 四路练满的 pattern 照原版（每路两项快、一项慢且来源单一，四路练满时间不同，挣学费的工牺牲一项属性；表在 `design/ORIGINAL_MAP.md`）。不照搬原版的数，要原版的体验；复刻还是改，都要给理由。
- 节奏目标：前两年钱紧；期末现金不过万；大卖不能是常态。情况好时第二年初能报中片，第三、四年拿中片，第四年有希望报大片。
- 用户倾向总体拉慢，手腕不能太好升，不然试镜玩法不成立。

**课、工、钱**
- 课和工都用“包装名（代码）”，按地图摆放（`data/new/map.json`）。同一个场所可以升级，不为升级开新工。
- 每天成败照原版公式；打工失败的那天没工钱，属性不加也不减，只加疲劳；学费按天扣。
- 舞蹈练体态，打扮是情人路的短板。慈善不加相貌。服务员只加谈吐 0·1（2026-11，不要再加别的）。临时在试的（GDD 标【临时】）：运私酒体力 +2、犯罪 +2、不扣相貌；新地点教堂，有个教堂帮工（义气或教育 0/1，体力 −1）。教堂义工（陪 Sil 去教堂）不加义气，加自律。
- 学费、收入按原版折，汇率 2G = 1 美元；生活费每月 15，开局 250；生活方式三种（普通、讲究、节食）。钱不会是负数。
- 片酬按试镜结果给，拍摄时就付，不看上映。
- 看书的入口先不开，书以后靠机遇得到。

**选片和试镜**
- 选片板固定 15 块：1924–25 年 3、9 月，1926–28 年 3、7、11 月，1929 年 3、7 月。每块 1 大 1 中 1 小，1924–25 年多一个小片。人脉 ≥50 时从备用池按顺序多一个。报名只看名气和路外属性。“下次选片”页随时能看。
- 开局四路都是 1 级。开局声望不写死，由底值和开局三问算出。
- 对手组牌要防被克（GDD 7.5）。
- 临时换角和抢角保留，跟着事件系统走，但测平衡期间单独开着。试镜前给说明页；临时换角可以不去，抢角不能拒绝，要写明抢的是哪个角色、是谁抢的。
- 相貌低于 60 是“身材走样”，不能试镜：选片板照常弹出，角色变灰、写明原因，和别的报不了一样。状态标签系统：检查各种状态、显示在属性栏（例：重病过又活下来是“不死鸟”，演太多小片是“低成本演员”，要演中片、大片洗掉）。以后会加更多标签（GDD 2.7）。

**平衡**
- 目标分布和“现在的判断”在 CLAUDE.md。现在到不了 S 是正常的，不为出 S 调数。
- 三种打法（自律、坏孩子、用药）要拉开；各路、各线的玩法要有区别，不为平衡做成一样。
- 失控这个数值不要（它是一刀切的惩罚）。取代它的是“开小差”【定】：疲劳刻度 − 自律刻度（0–33%），跑了整旬换成外出，按最高的属性挑地方，拍片的旬也会跑（GDD 5.1.1）。
- 属性刻度和档位【定】：基础属性按除数折成 0–100 的刻度，档位低/中/高/很高通用；事件条件写档位或刻度，不写原始数字，调平衡只改除数（GDD 2.1.1）。
- 被捕只来自犯罪工。犯罪工是放贷、运私酒、楼上房间（2026-11）。重病强制疗养院、拍摄违约保留。
- 每天教育 −1 的早期工是坐旗杆（名气 +0·1，唯一加名气的工），不做马童（2026-11）。
- 随机数状态留在存档里，SL 刷不了（2026-11）。
- 顺序：先做规则和数、跑机器人、用户试玩，剧情和事件放到试玩以后；跑机器人前先把每个机器人的策略列给用户确认（2026-11）。
- 两路都练的玩法走不通没关系，不为它调数。
- 数值合理就直接改，不用逐条问；改完记进 `design/BALANCE_LOG.md`。

**内容和界面**
- 事件现在全部关掉，瓦伦不去世（开关在 `events.json`）。大事件按故事节奏排，不必符合史实。
- 名字都是占位；人物细节等用户给，不要自己编。
- 名气和声望一样能鼠标放上去看数值和来源。
- 和 Sil 谈话在家里；吸毒在地图上的毒贩那里；存读档在物品按钮下面；生活方式只显示价格。
- 收获季以后拆成一年四个事件（现在不做，见 PLAN）。
- 用户自己改 JSON，按 `data/USER_GUIDE.md`。换表这类大活单开一个分支做。
- 多语言：技术性的东西一律英文（字段名、id、代码、注释、检查输出、`data/new/README.md`、`design/IMPL_NOTES.md`、`data/USER_GUIDE.md`、`design/GLOSSARY.md`）；中文只放在数据表的显示字段里。设计文档和交接保持中文。
- 只把必须用户定的设计决策拿去问；占位内容、模型能自己检查的细节不要列给用户。
